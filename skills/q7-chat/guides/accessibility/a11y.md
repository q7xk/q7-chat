# Accessibility in Q7 Chat

Q7 Chat must be usable with keyboard only, screen readers, reduced motion, forced colors, and right-to-left (RTL) languages (Arabic, Hebrew, Persian).

## Skip to content

Provide a visually-hidden "Skip to content" link that becomes visible on focus, pointing to the main chat region (`#main-content`). This lets keyboard users bypass the rail and navigation.

```html
<a
  href="#main-content"
  class="sr-only focus:not-sr-only focus:absolute focus:top-2 focus:left-2 focus:z-50 focus:rounded bg-accent text-bg px-3 py-2"
  >Skip to content</a
>
<main id="main-content">…</main>
```

## Focus management

Ensure every interactive element is reachable via `Tab` and has a visible focus indicator. Do not remove focus outlines. Manage focus when opening/closing dialogs, drawers, and the onboarding wizard — return focus to the triggering element on close.

## ARIA and landmarks

Use landmark roles (`<main>`, `<nav>`, `role="dialog"` with `aria-modal`) and descriptive `aria-label`/`aria-labelledby` on buttons and icon-only controls. Announce dynamic status (online/offline, unread counts) via `aria-live` regions where appropriate.

## Reduced motion

Respect `prefers-reduced-motion` by disabling or simplifying transitions, the shared-axis view transition, and the morphing hero. Use `reduceMotion` from settings to gate animations.

## Forced colors and contrast

Respect `forced-colors` and `prefers-contrast`. Use `currentColor` for icons and ensure text meets contrast ratios against the dark theme (`--background`, `--foreground`).

## RTL support

Q7 Chat supports Arabic and Persian (`dir="rtl"`). Set `document.documentElement.dir` based on language (`ar`, `fa` → RTL). Use logical CSS properties (`margin-inline-start`, `padding-inline-end`) and `rtl:-scale-x-100` for mirrored icons. Test layout in both LTR and RTL.

## Fallback strategies

If a custom component cannot be made fully accessible, prefer a native HTML element (`<button>`, `<a>`, `<dialog>`, `<input>`) with built-in accessibility over a custom ARIA implementation.
